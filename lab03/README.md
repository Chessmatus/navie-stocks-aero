## Уравнение, графы и подбор параметров

Исходная акустика: $p_t=-K(u_x+v_y)$, $u_t=-p_x/\rho$, $v_t=-p_y/\rho$.
Для статических материалов её давление удовлетворяет

```math
p_{tt}=K\partial_x(\rho^{-1}p_x)+K\partial_y(\rho^{-1}p_y).
```

Начальные условия: опубликованное $p_0$ и $p_t(0)=0$. Неоднородная плотность
остаётся внутри производной. К двум потокам добавлены перекрёстный поток,
затухание, реакция и кубический член: шесть переключателей, 64 структуры.
Опорная маска 3 имеет только Fx,Fy; полная — 63. Дополнительные члены
нормированы T0=1 и P0=max|p0_train|, который одинаков для обучения, валидации, переноса и теста.

Масштабированный МНК/SVD подбирает коэффициенты только на обучении.
Для The Well используются приближённые слабые моменты с гауссовым сглаживанием
(1.4 кадра, 2 ячейки), гармоническими граневыми подвижностями и исключением
краёв ядра. Для CNO производные вычисляются по точной формуле.

NetworkX хранит дерево выражения и матрицу смежности с порядком аргументов.
Повторные операнды имеют отдельные вхождения. Динамическая структурная модель:
z(n+1)=Phi_G(z(n);rho,K)+noise, z=(p,p_t); временная развёртка ациклична.
Физическое семейство задано заранее; это не доказательство причинности
произвольных корреляционных связей.

## Диагностика лабораторной № 2 и новый критерий

Сохраняются 1000 блочных bootstrap-реплик, блоки 4/8/12 полных кадров,
95%-е интервалы, refit после удаления, условный шум остатков и W1/SD0.
Исходное консервативное правило помечает ветвь как необходимую, если
интервал не содержит ноль, либо верхняя граница прироста ошибки моментов
выше 0.01, либо W1/SD0>1, либо вывод неустойчив по блокам.
Эта метка теперь **не запрещает** граф. Для b_j=1 у таких ветвей:

```math
B(G)=\frac16\sum_{j\notin G}b_j,\qquad 0\le B(G)\le1.
```

Новая целевая функция:

```math
J(G)=E_p(G)+0.1E_m(G)+0.02N(G)+0.5E_{int}(G)+0.01B(G).
```

E_p — относительная L2-ошибка **давления прямого решения на валидации**;
E_m — нормированная ошибка дифференциальных моментов; N — число ветвей;
E_int — средняя ошибка **давления** на двух дополнительных траекториях.

```math
E_{int}(G)=\frac12\sum_{k=1}^{2}
\frac{\|p_G^{(k)}-p_{ref}^{(k)}\|_2}{\|p_{ref}^{(k)}\|_2}.
```

The Well: valid/sample_1 и sample_2, каждая со своим p0, rho, c и эталонными
будущими кадрами. В солвер поступают только начальное поле и свойства среды.
Коэффициенты и нормировка P0 остаются обучающими. Меняются и возбуждение,
и геометрия; это проверка совместного переноса, а не изолированный do-опыт.
CNO: seed 3104/3106, эталон каждой реализации вычисляется по точной формуле.

Масштабированные и транспонированные эталоны исключены из критерия.
Остаточное зашумление и bootstrap отдельно проверяют устойчивость оценок;
CNO с 1% шума в обучающем p_tt сохраняется как дополнительный опыт.
Новые траектории — численные данные, не физические измерения.

Жёсткий фильтр проверяет пространственный тензор, устойчивость расчёта и
грубую ошибку давления на валидации ≤50%. Ранний отказ разрешён только по
сертифицированной нижней границе: уже накопленная сумма квадратов ошибок
выше 0.5² от суммы квадратов всей эталонной траектории. Будущие ошибки
неотрицательны. Такой отказ не исключает ни исходную модель, ни старый
граф с затуханием — они сравниваются общей целевой функцией.

## Прямые солверы

The Well: Clawpack 5.9, unsplit MC, CFL 0.9. Диагональная анизотропия задаётся
точным масштабированием координат. Перекрёстное взаимодействие, реакция и
кубический член используют Strang/RK4-источник. Вспомогательная память m:

```math
p_t=-K\nabla\cdot u+m,\quad
u_t=-A\nabla p/\rho-d u,\quad
m_t=-dm-rp-np^3/P_0^2
```

даёт именно p_tt=K div(A grad(p)/rho)-d p_t-rp-np³/P0².
Коэффициенты не переподбираются по валидации или тесту. Кэш включает
параметры, ошибки, причины отказа и версию солвера. Тестовые файлы в
вычислении валидационного критерия не читаются.

CNO: синусный Galerkin с 32 модами и DOP853, rtol=1e-9; L2-норма давления
вычисляется в коэффициентах по ортогональности. Нелинейность проецируется
с деалиасингом. Одна и та же процедура применяется ко всем кандидатам;
исходная волна сверяется с независимой точной формулой. Для нелинейных
моделей остаётся погрешность усечения базиса. Независимый центральный
солвер сохранён для проверки чувствительности к дискретизации.

## Семплирование с отклонением и корректность

G предлагается равномерно из 64 масок; U~Uniform(0,1) независимо от G.
Если выполнены ограничения I(G)=1, принимаем при U≤exp(-J/T).
Поскольку J≥0, ненормированная масса q(G)I(G)exp(-J/T) ограничена q(G).
Условное распределение принятых графов пропорционально этой массе.

3 раунда по 5000 предложений. Следующая T использует квартиль принятых
оценок прошлого раунда, снижение в 0.65 раза и нижнюю границу 0.04.
Внутри раунда T и оценки фиксированы. Маски, U, принятия и причины отказов
сохранены, повторы не удаляются. Разные T не считаются одним posterior.

Малое семейство позволяет точный аудит 100000 предложений и полный перебор.
Преимущество по скорости над перебором не заявляется. За конечный бюджет
нет общей гарантии глобального оптимума вне этой библиотеки.

## Воспроизведение

Из корня проекта:

```sh
python -m pip install -r lab03/requirements.txt
python -m lab03.run --bootstrap 1000
python -m lab03.plotting
python -m lab03.build_notebook
python -m lab03.execute_notebook
python -m lab03.build_deliverables
python -m pytest tests/test_lab03_acoustics.py -q
```

Приложенные кэши и результаты позволяют повторить выбор без пересчёта
всех валидационных PDE. Для их восстановления нужен отдельный Clawpack:

```sh
micromamba create -y -p .clawpack -f lab03/clawpack.yml
python -m lab03.run
```

Скрипт использует последовательный PyClaw и отключает ненужный импорт
PETSc/MPI в этом процессе. Для macOS arm64 есть explicit lock-файл.
Кэш защищён блокировкой и записывается атомарно. Генерация PDF:
`tectonic --outdir lab03 lab03/presentation.tex` или XeLaTeX из lab03.

Повторная загрузка новых тестовых данных:
`python -m lab03.fetch_data --split test --sample 2`.
Данные переноса: `--split valid --sample 1` и `--split valid --sample 2`.
Остальные источники: `--split train`, `--split valid`, `--cno`.
