# Экспериментальные данные

Единственный используемый набор — случай 1L из
[DataverseNO, DOI 10.18710/SX0ZQT](https://doi.org/10.18710/SX0ZQT), версия 1,
лицензия CC0. Авторы данных: Hillestad, Yadala, Li, Hearst, Worth.
Исходное описание эксперимента: [`turbine_1L/00_README.txt`](turbine_1L/00_README.txt).

`turbine_1L/measurement_crop.npz` — компактный фрагмент именно этих
экспериментальных полей, используемый обоими солверами. Он не является
результатом численного моделирования.

| Ключ NPZ | Содержимое |
|---|---|
| `x`, `y`, `z` | Одномерные оси пространственной сетки, метры |
| `velocity` | Массив `[18, 53, 33, 33, 3]`, компоненты `(u,v,w)`, м/с |
| `frame_ids` | 2732, 2737, …, 2817 |
| `times` | 0, 0.01, …, 0.17 с относительно первого выбранного кадра |
| `absolute_frame_times` | Время относительно начала исходной записи |

Координаты исходных текстовых файлов переводятся из миллиметров в метры.
Исходная частота 500 Гц; выбран каждый пятый кадр. Пространственный фрагмент
содержит расчётную область и дополнительные узлы для интерполяции её границ.
SHA-256 компактного файла и параметры происхождения сохранены в
[`../metadata/data_manifest.json`](../metadata/data_manifest.json).

Для повторной загрузки полнообъёмных кадров из корня репозитория:

```sh
python fetch_experiment.py --frames 2732 2737 2742 2747 2752 2757 2762 2767 2772 2777 2782 2787 2792 2797 2802 2807 2812 2817
```

Индекс архива включён в Git. Скрипт скачивает только нужные диапазоны ZIP,
проверяет CRC32 и сохраняет SHA-256. Полные кадры, ZIP-кеши и установленное
окружение остаются локальными. Компактный файл читается автоматически:

```python
from lab01.experiment import prepare_measurements
measurements = prepare_measurements('data/turbine_1L')
```

Чтобы проверить полное восстановление обрезки, после загрузки кадров
сохраните существующий NPZ под временным именем и вызовите
`prepare_measurements` повторно. Функция использует NPZ как кеш, когда он
существует, и восстанавливает его из текстовых кадров, когда кеш отсутствует.
[`subset_provenance.json`](turbine_1L/subset_provenance.json) описывает
исходные выбранные кадры; их отсутствие в Git намеренное.
