# FEniCSx для лабораторной

Изолированное окружение Conda находится в `.fenicsx/`; исходное окружение
ноутбука `.venv/` сохранено. Использована сборка conda-forge для macOS arm64:
DOLFINx 0.11.0, Python 3.12, MPICH и PETSc. Локальный менеджер Conda — micromamba.

Воспроизведение окружения с установленной Conda:

```sh
conda env create --prefix .fenicsx --file environments/fenicsx.yml
conda activate ./.fenicsx
python run_fenics_experiment.py --phase verify
python run_fenics_experiment.py --phase primary
```

В уже установленном окружении:

```sh
.fenicsx/bin/python run_fenics_experiment.py --phase verify
.fenicsx/bin/python run_fenics_experiment.py --phase primary
```

MPI инициализирует локальную сеть даже при одном процессе. В песочнице Codex
этим командам требуется разрешённый запуск вне песочницы.
Скрипт на macOS задаёт `FI_PROVIDER=tcp`: автоматический выбор libfabric
на этой машине приводил к ошибке завершения MPI через VPN-интерфейс.
Число потоков OpenMP/OpenBLAS по умолчанию ограничено одним.
Точная спецификация установленных пакетов: `environments/fenicsx-osx-arm64.lock`.
Короткая проверка окружения и постоянного течения:

```sh
.fenicsx/bin/python run_fenics_experiment.py --phase check
```

`lab01/fenics_solver.py` реализует трёхмерную систему скорости–давления:
тетраэдры, скорость P2, давление P1, инкрементальную коррекцию давления IPCS,
Crank–Nicolson и экстраполяцию AB2 для переносящей скорости. Противопоточная
схема и искусственная вязкость не добавляются. Задана измеренная скорость на
всей границе подобласти; после коррекции общего потока приращение давления
имеет однородные условия Неймана. Постоянное ядро задачи Пуассона удаляется,
давление имеет нулевое среднее. Начальное давление экспериментального расчёта
равно нулю, поскольку в архиве оно не измерено.

Формулировка адаптирована из [учебника DOLFINx](https://jsdokken.com/dolfinx-tutorial/chapter2/ns_code2.html).
[Официальная установка](https://fenicsproject.org/download/).

Проверка `verify` использует аналитическое переносимое поле Бельтрами,
включая точное начальное давление, при экспериментальном масштабе вязкости.
Это проверка численного метода, а не второй экспериментальный набор.
Сравнение с MAC проводится в тех же 539 физических точках.

Эксперимент `primary` использует те же 18 измеренных кадров случая 1L,
те же точки, временные окна и интерполяцию измерений, что MAC. Численные
пространства и начальные проекции различаются. На контроле начальное поле
переустанавливается из измерений; границы известны в течение всего окна.
Следовательно, проверяется условное воспроизведение течения.

Результаты сохраняются отдельно в `outputs/turbine_1L/fenicsx/`.
IPCS с P2/P1 не обеспечивает поточечно нулевую дивергенцию: её RMS в отчёте
нельзя приравнивать к машинной точности дискретной MAC-проекции.

В выполненном эксперименте 10 октября 2026 ошибка на контрольном окне после
подбора вязкости составила 28.16% для основной сетки FEniCSx против 24.46% для
MAC. Обе оптимизации пришли к верхней границе ν=1.8e-6 м²/с.
На опорной вязкости ошибка FEniCSx по сеткам 12×8×8, 18×12×12, 27×18×18
составила 30.10%, 28.70%, 27.85%. Изменение шага времени 0.001→0.0005 с
на основной сетке почти не меняет ошибку относительно измерений.

На аналитическом тесте с масштабом вихря 32 мм ошибка вихревой части
FEniCSx на основной сетке — 6.09%, MAC — 32.44%; при масштабе 16 мм —
43.68% и 61.16%. Улучшение на точном поле не означает улучшения на этих
обработанных измерениях. Сильная дивергенция заметна и не уменьшается
систематически при сгущении сетки; сеточная сходимость не подтверждена.
Эта реализация IPCS требует доработки прежде, чем её точность можно считать
достаточной для восстановления физической вязкости.
