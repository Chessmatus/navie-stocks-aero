# Материалы курса

Файлы предоставлены пользователем как исходные материалы лабораторной.

- `laboratory_requirements.pdf` — требования к лабораторным работам;
  исходное имя: `Требования_к_лабораторным_работам (1).pdf`.
- `intro_symbolic.pdf` — материалы по символьному представлению уравнений.
- `Sologub_PHDpresentationlog.pdf` — предоставленный пример презентации.

Статья и экспериментальный архив доступны по DOI, указанным в основном
[README](../../README.md); PDF статьи в этот раздел не добавлен.
