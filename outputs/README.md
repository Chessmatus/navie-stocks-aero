# Результаты вычислений

`turbine_1L/` содержит текущую лабораторную по одному эксперименту:

- `experiment_summary.json` — сводный отчёт MAC, подбор и проверки сетки/шага;
- `primary.json`, `coarser.json`, `finer.json`, `half_time_step.json` — отдельные запуски;
- `solution_primary.npz` — поля MAC, измерения и результаты в общих точках;
- `predictions_*.npz` — значения для сравнения на разных дискретизациях;
- `navier_stokes_tree*` — одно актуальное дерево, словарь операций и матрица;
- `time_series.png`, `slice_comparison.png`, `viscosity_profile.png` — графики MAC;
- `solver_diagnostic.json` — проверка переноса точного вихревого поля;
- `fenicsx/` — отчёты, решения и графики дополнительного расчёта FEniCSx.

`legacy/` сохраняет рисунки и деревья прежних постановок. Они не используются
текущим ноутбуком и не являются дополнительными экспериментальными данными.

Итоговые отчёты и поля включены в репозиторий для проверки результатов.
Промежуточные `*_progress.json` и `fit_latest_*.npz` исключены из Git:
их содержимое воспроизводится запуском соответствующего эксперимента.
