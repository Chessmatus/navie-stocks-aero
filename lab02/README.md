## Математическая постановка

Нормировка студента: e = sqrt(epsilon0) E, h = sqrt(mu0) H.
В однородной области вне источников при mu_r = 1:

$$\partial_t\mathbf e=\frac{c}{\epsilon_r}\nabla\times\mathbf h
-\frac{\sigma}{\epsilon_0\epsilon_r}\mathbf e,\qquad
\partial_t\mathbf h=-c\nabla\times\mathbf e.$$

Вместо тысячи расчётов полной 3D-сетки используется гармоническое TEM-решение
E(x,t) = Re(E0 exp(-gamma x) exp(i omega t)). Наблюдаются затухание alpha
и фазовый коэффициент beta, gamma = alpha + i beta. Частоты не являются
временными кадрами. Исследуем эффективную слабозатухающую редукцию:

$$\alpha=a\sqrt{f/f_0}+b(f/f_0),\qquad
\beta=2\pi f n/c+a\sqrt{f/f_0},\qquad f_0=10\text{ ГГц}.$$

Параметры: n — эффективный показатель преломления; a — проводниковый вклад
с поверхностным импедансом, пропорциональным (1+i)sqrt(f); b — дополнительный
частотный член потерь. Это наша редукция для второй лабораторной, а не формула,
которую подбирали авторы экспериментальной статьи. n² — эффективный фон,
не независимо измеренная проницаемость объёмного материала.

Решение совместимо с уравнениями Максвелла на каждом тоне при
ε_eff = c²(beta²-alpha²)/omega² и sigma_eff/epsilon0 = 2 c² alpha beta/omega.
Волновой импеданс задаёт h_hat = c gamma e_hat/(i omega).
Частотная эффективная среда не заменяется без обоснования постоянными
коэффициентами исходного временного PDE на любой полосе частот.

## Тройка методов и её обоснование

1. **Moving-block pairs bootstrap**, 1000 реплик. Перевыбираются соседние
   частотные строки совместно с обоими каналами, чтобы сохранить локальную
   корреляцию. Основная длина блока 8; проверка 4 и 12. Блоки не пересекают
   разрывы обучения. Предположение о локальной зависимости частотных остатков
   является модельным; без него формальных гарантий покрытия не заявляется.
2. **Условное зашумление** alpha, beta либо обоих каналов. На обучении
   оценивается локальный по частоте масштаб остатка s_j(f); центрированные
   стандартизованные остатки перевыбираются парными блоками. К наблюдениям
   добавляется lambda s_j(f) z*_j, lambda = 0, 0.5, 1, 2, 4.
   На каждой бутстреп-реплике — новая реализация вмешательства. Это смесь
   неопределённости выборки и вмешательства, а не один фиксированный испорченный набор.
   Это вычислительное вмешательство в извлечённую gamma, не физическое изменение линии.
3. **Wasserstein-1** между эмпирическими выборками параметров. Не требует
   оценивания плотности и остаётся определённым при непересекающихся выборках.
   Сохраняются расстояния в физических единицах и в единицах исходного SD.
   Совместное распределение дополнительно сравнивается через 128 фиксированных
   проекций: приближённое sliced-W1, не точное многомерное W1.

Сравниваются взвешенная квадратичная ошибка и soft-L1. Первая решается линейной
алгеброй; вторая — SciPy TRF. Масштабы наблюдений зафиксированы до вмешательства;
для разных функций ошибки исходные SD свои. Для сравнения в исходных единицах
в ноутбуке также приведены ненормированные расстояния.

Оценки a и b допускают знак для корректного изучения окрестности нуля без
скопления бутстреп-оценок на ограничении. Отрицательный отдельный коэффициент
не интерпретируется как физическая активная среда; это диагностический базис.
На рабочей полосе суммарное затухание выбранных моделей положительно.

## Данные и протокол

Синтетика: 151 частота, 3–18 ГГц; истинные (n,a,b)=(2,0.06,0).
Добавлен неоднородный AR(1)-шум с rho=0.6. Наличие известного нулевого b
позволяет проверить, удаляется ли именно отсутствующий член.

Измерения: воздушная коаксиальная линия Maury Microwave 8045P. В 10 положениях
от 0 до 192 мм перемещался пропускающий и отражающий элемент без переподключения
кабелей. Исходные S-параметры измерены тремя VNA; из них неизменённый авторский
алгоритм извлекает gamma. Данные измерений включены целиком для выбранного опыта:
30 небольших Touchstone-файлов. Объёмные временные E/H в этом опыте не измерялись.

Основной набор — ZNA (151 частота, 3–18 ГГц). ENA (3–14 ГГц) и VectorStar
(3–18 ГГц) оставлены для проверки между приборами. Это та же физическая линия,
не три независимых материала. Учебное разбиение: каждая четвёртая полоса из 8
частот — контроль; 119 точек обучения и 32 контроля. Пилотная модель и шум
определяются исключительно по обучению. Контроль используется при выборе
структуры, поэтому не называется независимым окончательным тестом.

Повторно проверен старый код: аналитический подбор ε_r = 4.000000001 при эталоне 4;
ошибки FDTD на сетках 12³ и 24³ относятся примерно как 3.913.
Это согласуется со вторым порядком схемы Yee. Основной бутстреп использует
гармоническое решение, а не скрытые повторные запуски 3D FDTD.

## Критерий удаления

Правило выбора применяется к основной квадратичной ошибке; soft-L1 — отдельная
проверка чувствительности распределений к функции ошибки.

Большое расстояние распределений само по себе не означает ненужность ветви.
Решение об удалении принимается только одновременно при четырёх условиях:

1. 95%-й процентильный интервал содержит нулевой вклад (n=1 либо a=0, b=0).
2. После фиксации нулевого вклада остальные параметры заново подобраны;
   верхняя 95%-я граница прироста контрольного нормированного RMS <= 0.25.
3. При lambda=1 и шуме обоих каналов W1/SD0 <= 1.
4. Удаление подтверждается при длинах блока 4, 8, 12.

Пороги 0.25 и 1 заранее заданы как учебные допуски, не получены из теоремы
и не выдаются за общепринятые уровни значимости. Для оценки прироста ошибки
перевыбираются отдельно обучение и контроль; проверочные полосы длины 8
не могут образовывать блоки 12, поэтому для их перевыборки используется максимум 8.

| Элемент | Синтетика | Измерения | Что меняется в графе |
|---|---|---|---|
| n | Сохранить | Сохранить | Вклад в фазу относительно n=1 |
| a | Сохранить | Сохранить | Общий узел и оба пути в alpha и beta |
| b | Удалить | Сохранить | Ветвь b(f/f0) и её вход в alpha |

На синтетике b действительно равен нулю. На измерениях его основной интервал
[0.000427, 0.005982] Нп/м не содержит нуля, хотя после удаления ошибка почти не меняется.
При блоке 12 вывод меняется, поэтому устойчивое удаление не подтверждено.
Решение сохранить b консервативно; оно не доказывает конкретный механизм потерь.
Сохранены выбранные графы и матрицы отдельно для обоих наборов.

## Ограничения

Частотный бутстреп не учитывает полную метрологическую неопределённость VNA,
длин, коррелированных систематических ошибок и этапа извлечения gamma.
Остатки содержат и шум, и ошибку модели. SD-нормированные расстояния относятся
к фиксированному бутстрепу; их значение не является вероятностью гипотезы.
Оценка уровня Монте-Карло относится только к конечной выборке параметров.
Выводы ограничены данным режимом, полосой и эффективным базисом. Они не разрешают
удалять фундаментальные роторы или саму ветвь проводимости в системе Максвелла.

## Запуск и файлы

Из корня общего репозитория, Python 3.12:

```bash
python -m pip install -r lab02/requirements.txt
python -m lab02.run --bootstrap 1000 --rebuild-data
python -m lab02.execute_notebook
python -m pytest -q
```

Исходные измерения уже включены; интернет нужен только для установки зависимостей.
Полный запуск ноутбука заново извлекает gamma, считает бутстреп, строит графики
в ячейках и сохраняет результаты. Исходная первая лабораторная не изменена.

- `model.py`, `statistics.py`: физическая редукция, оценка параметров, интервенции и метрики.
- `experiment.py`, `data.py`, `plotting.py`: полный вычислительный эксперимент.
- `vendor/`: атрибутированные неизменённые чужие исходники.
- `data/measurements/`: исходные экспериментальные S-параметры.
- `results/report.json`: числа, интервалы, допуски и решения.
- `results/bootstrap_samples.npz`: все выборки параметров, расстояния и конфигурация.
- `results/*graph.json`, `*adjacency.npy`: графы до и после отбора.
- `results/*maxwell_expanded*`: исходная структура Maxwell RHS с подстановкой эффективных коэффициентов.
- `results/parameter_graph_map.json`: связь с исходными узлами студента; его `gamma` означает sigma/epsilon0 [1/с], не комплексную gamma [1/м].
- `figures/`: рисунки, которые также строятся в ноутбуке.

Обновление файлов представления после расчёта:
`python -m lab02.build_deliverables`. Для сборки PDF нужен XeLaTeX-совместимый
Tectonic: `cd lab02` и `tectonic presentation.tex`.
