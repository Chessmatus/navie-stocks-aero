# Устный рассказ: примерно 5–7 минут

1. **Цель.** Во второй лабораторной надо решить, какие части графа модели необходимы.
   Для этого я исследую изменение распределений параметров после вмешательства в данные.
   Взята тема Microwave circuits wave propagation и первая лабораторная другого студента.
2. **Физика.** Основа — уравнения Максвелла. Из них беру гармоническую бегущую волну:
   у неё есть затухание alpha и фазовый коэффициент beta. Их частотная зависимость
   описана тремя параметрами. n задаёт скорость; a учитывает проводниковые потери
   и связанную с ними фазовую поправку; b — дополнительный частотный вклад потерь.
   Это эффективная редукция, а не новая универсальная форма Максвелла.
3. **Старый код и данные.** Я использую исходный граф, аналитические волны, оптимизатор
   и FDTD-проверку студента. Его внешние данные синтетические. Поэтому для реальной
   части добавляю опубликованные VNA-измерения воздушной коаксиальной линии из статьи
   Hatab. Из S-параметров авторским методом получаю комплексную gamma. Никакие
   нарисованные временные поля не выдаются за измерения.
4. **Метод.** Беру 1000 блочных бутстреп-реплик: соседние частоты и два канала идут вместе.
   Интервенция добавляет блочный шум с частотно зависимым масштабом, оцененным по обучению.
   Проверяю отдельно alpha, beta и оба канала при пяти уровнях шума. Затем заново подбираю
   параметры и измеряю Wasserstein-1. Обоснование: сохраняю локальные зависимости,
   учитываю неоднородность шума и работаю непосредственно с эмпирическими распределениями.
5. **Граф.** Коэффициент a используется в двух ветвях — и затухании, и фазе. Убирать
   только один его путь физически неправильно. b относится к одной дополнительной ветви.
   Для n проверяю замену на единицу, то есть удаление поправки к вакуумному фону.
6. **Графики.** При увеличении шума распределения параметров расширяются, расстояния растут.
   Между a и b есть компенсация. Поэтому показаны не только гистограммы, но и совместное
   облако, а также расстояние по проекциям. На графиках есть квадратичная ошибка и soft-L1.
7. **Выбор.** Чувствительность сама по себе не значит, что член надо удалить. Нужны
   интервал, содержащий нулевой вклад, малая потеря качества после повторного подбора,
   приемлемая устойчивость и согласие трёх длин блока. В синтетике b заранее равен нулю —
   метод разрешает его удалить. На реальных измерениях решение меняется при изменении
   блока, поэтому b сохраняется. n и a нужны в обоих случаях.
8. **Ограничения.** Это условная частотная оценка, а не полная метрологическая
   неопределённость. В остатках может быть ошибка модели. Пороги удаления учебные,
   а контроль уже участвовал в выборе структуры. Вывод касается этой линии и этой полосы.

## Короткие ответы на вопросы

- **Решается ли PDE?** Используется его гармоническое решение в классе TEM-мод;
  старый 3D FDTD отдельно проверен. Бутстреп оценивает параметры этой физической редукции.
- **Почему не только данные автора первой работы?** Они оба синтетические;
  задание требует также реальные данные с интервенцией.
- **Почему не удалить b на измерениях, если ошибка почти та же?** Основной интервал
  не содержит нуля и решение зависит от блока. Недостаточно оснований для устойчивого удаления.
- **Почему допускаются отрицательные коэффициенты?** Это локальный диагностический
  базис для оценки нулевого вклада; ограничение неотрицательности исказило бы бутстреп у нуля.
  Отрицательный отдельный коэффициент не называется физическим усилением.
- **Граф причинный?** Это граф вычисления формулы. Интервенция вычислительная;
  причинные выводы о материале из такого опыта не заявляются.
